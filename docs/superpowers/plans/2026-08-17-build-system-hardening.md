# Build System Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close identity drift between package version, checked-in workflows, and smoke tests; dogfood Phase 1 from this checkout; and make the next version bump a single, test-enforced process.

**Architecture:** Keep hatchling + uv + GitHub Actions as the build spine. Add a repo-level projection contract so `machinist.yaml` plus `pyproject.toml` version must equal the committed managed workflows. Extract one wheel smoke script used by CI and release. Add `github.spec_install` (`pypi` default, `checkout` for this repository) so the packaged template still pins PyPI while this repo's Spec workflow runs `uv sync --frozen` and `uv run machinist spec`. Leave Execute local. Do not bump the published version in this work; document under `## Unreleased`.

**Tech Stack:** Python 3.12+, uv, hatchling, pytest, GitHub Actions, pydantic `extra="forbid"` config, `importlib.resources` templates.

## Global Constraints

- Domain language from `CONTEXT.md`: Task, Phase, Spec, Approval, Gate, Task Run, Claim, Workshop (code class remains `Workspace`), Harness, Evidence.
- Tests never touch the network: no live `gh`, PyPI, or harness subprocesses in pytest. Packaging tests inspect local `dist/` after `uv build`.
- Docs are under test: every `docs/getting-started.md` ` ```yaml ` block must parse as top-level `MachinistConfig`; do not follow `machinist` with a bare lowercase word unless it is a real subcommand.
- Unknown `machinist.yaml` keys fail (`extra="forbid"`). New keys need template, getting-started reference YAML, and `test_config.py`.
- After config that affects GitHub Actions: update `src/machinist/templates/github/`, projection tests, then `uv run machinist sync-workflows` and `--check`.
- Controller never merges. Do not commit `.machinist/runs/` or secrets.
- Do not add ruff/mypy to `tests.command` (the product test gate). Lint stays out of harness Execute.
- Do not SHA-pin Actions in the first eight tasks (optional Task 11).
- Do not add Windows CI (not claimed). Python 3.13 is in-scope for this repo's CI only.
- Stay on package version `0.2.0` until a later release; changelog uses a new `## Unreleased` section.
