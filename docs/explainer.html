Machining GitHub Issues Into Reviewable Pull Requests

Connect GitHub issues to coding harnesses through a human Approval bound to the exact Spec head before implementation starts.

Claude Code OpenCode Codex Pi

Uncontrolled AI Agents

  • Hallucinate unwanted architecture changes
  • Push unverified commits directly to main
  • Break existing test suites without warning
  • Lack clear checkpoint between planning and coding

The Machinist Guardrails

  • Generates a draft Spec PR before implementation
  • Requires human approval bound to exact commit SHA
  • Executes inside isolated Git worktrees
  • Runs every configured verification gate before readying the PR
01

Issue labeled agent-task with clear criteria

🔒 Absolute Invariant: AgentMachinist NEVER clicks merge. Final review and merge stay with you.
bash — machinist operator loop
$ machinist spec 42 ... reading issue #42: "Add CSV export for filtered rows" ✓ Created draft PR #18 with .machinist/specs/issue-42-spec.md ... awaiting human review and approval $ machinist approve --issue 42 ... approval requested; workflow checking write access and current head ✓ Approval recorded for a17c98d42e6f by @operator $ machinist run 42 ... provisioned worktree ~/.machinist/workspaces/repo-issue-42 ... claude-code implemented requirements ... running test gate: uv run pytest ✓ 185 passed in 4.2s (quality gate passed!) ✓ Pushed with lease; converted PR #18 to READY FOR REVIEW
