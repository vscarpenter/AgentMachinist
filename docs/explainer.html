Custody checks

Reduced credentials and protected Git metadata detect violations. This is not an OS sandbox.

Recoverable local work

Failed runs retain Evidence and need explicit retry. Amendments need a new Spec, Approval, and Review.

Optional publication

GitHub PRs and GitLab MRs use origin binding and leased pushes. Repeating publication reuses successful local work.

CAPTION
A local Task, an exact human-approved Spec, and a reviewed candidate. Publication is optional.

AgentMachinist 0.14.0 includes the local workflow and optional GitLab support. This is an animated illustration, not a live Harness or hosted publication demonstration. machinist rehearse runs the production local path in a temporary repository with a deterministic fake Harness.

GitLab support covers issue import and MR publication, including nested projects and explicit self-managed hosts. It does not include hosted GitLab Spec CI or remote GitLab Approval. A local model requires separate configuration and offline validation.
